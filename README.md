# Course Helper App

A web application built to help users manage their courses with functionalities to add, update, and delete courses. It also supports user authentication with sign-in and sign-out features. The application utilizes Hono for the server, Postgres as the database, and Postgres Accelerate for optimized queries. Additionally, a custom npm package for datatype checks is published and used across both the frontend and backend.

## Features

- **User Authentication**: Users can sign in and sign out of the application.
- **Course Management**: Add, update, and delete courses.
- **Optimized Database**: Postgres Accelerate is used for efficient database queries.
- **NPM Package**: A custom npm package for datatype checks is used across the app.
- **API Integration**: Axios is used for making API requests to the backend.

## Tech Stack

- **Frontend**: [React/Vanilla JS]
- **Backend**: Hono (Lightweight web framework)
- **Database**: PostgreSQL with Postgres Accelerate
- **Authentication**: HONO - JWT library
- **API**: Axios (for HTTP requests)
- **NPM Package**: Custom package for datatype checks
